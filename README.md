Welcome to the Chatbot project developed during my internship with CodeAlpha.
This project demonstrates a simple conversational chatbot built using Python and Streamlit.

🚀 Features

✔ interactive chatbot responses
✔ name memory (remembers user name)
✔ mood-based replies
✔ movie recommendations
✔ simple rule-based conversation
✔ web-based UI using Streamlit

🛠 Tech Stack

Python

Streamlit

Session State (for memory)

Rule-based logic

📦 Installation

Clone the repository:

git clone https://github.com/your-username/CodeAlpha_Chatbot

Navigate to project folder:

cd CodeAlpha_Chatbot

Install dependencies:

pip install -r requirements.txt
▶️ Run the Application
streamlit run app.py
💡 How It Works

chatbot responds based on keywords

remembers user name during session

provides basic mood-based replies

recommends movies on request

interactive web interface
